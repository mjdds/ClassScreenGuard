# 教室屏幕操作锁

<img src="icon.png" alt="教室屏幕操作锁图标" width="128" />

ClassScreenGuard 是一个适用于 ClassIsland 2.x 的 Windows 屏幕操作锁插件。锁定后保留当前屏幕画面，不显示全屏遮挡层，同时隔离鼠标、触摸和普通键盘输入，适用于需要临时限制教室电脑操作的场景。

## 功能

- 当前画面和正在播放的内容保持可见。
- 透明输入隔离层覆盖所有显示器，全局鼠标钩子只放行锁屏层和密码框，拦截其他窗口的鼠标、触摸和长按操作。
- 锁定期间关闭通知中心、开始菜单和搜索等 Shell 浮层，防止通知长按菜单或底部上滑绕过锁屏。
- 锁定期间拦截普通按键及 Windows 键、Alt+F4、Alt+Tab 等组合键。
- 按 `Ctrl+Alt+L` 锁定；锁定后再次按下可打开独立密码框。
- 主显示器右下角提供常驻「解锁」按钮，可使用鼠标或触摸打开密码框。
- 密码框提供可点击的「解锁」按钮，也可以按 Enter 提交。
- 普通密码最多连续输错 10 次，之后必须等待 5 分钟才能继续尝试。
- 失败次数和冷却截止时间会持久化，关闭密码框或重启插件不会绕过等待。
- 密码框打开时不再反复抢占焦点，支持实体键盘、Windows 触摸键盘和屏幕键盘输入。
- 任意锁定状态下连续输入正确的 Admin 密码即可解控，并显示一秒「Admin 解锁」提示，无隐藏 Admin 界面。
- 密码修改区域默认隐藏，连续点击设置页版本号 5 次后显示。
- 注销后可在下次启动时恢复锁定；关机或重启会清除恢复状态，避免次日开机误锁。
- 可配置允许锁定时段，时段外拒绝新锁定并自动解除已有锁定，支持跨午夜。
- 首次设置管理员密码无需原密码；已经设置后，必须输入正确的原管理员密码才能修改。
- 普通密码与管理员密码均使用随机盐和 PBKDF2-SHA256 哈希保存，不保存明文。

## 运行环境

- ClassIsland 2.x（插件 API 2.0.0.0 或更高版本）
- Windows 10/11
- 构建项目需要 .NET 8 SDK

本插件使用 Windows 输入钩子和窗口 API，不支持 Linux 或 macOS。

## 安装

### 插件市场

上架审核通过后，在 ClassIsland 的插件市场中搜索「教室屏幕操作锁」并安装。

### 手动安装

1. 下载 [`ClassScreenGuard.cipx` 1.4.0.0](https://github.com/mjdds/ClassScreenGuard/releases/download/1.4.0.0/ClassScreenGuard.cipx)，或获取本地构建的插件包。
2. 在 ClassIsland 的插件设置中安装该 `.cipx` 文件。
3. 按 ClassIsland 提示重启或重新加载插件。

## 使用方法

1. 在 ClassIsland 设置中打开「屏幕操作锁设置」。
2. 连续点击版本号 5 次，展开密码修改区域。
3. 分别设置并保存普通解锁密码和 Admin 密码，均至少 4 个字符，建议使用 8 位以上密码。Admin 全局连续输入建议使用键盘可直接输入的字母、数字和符号，不依赖中文输入法候选。
4. 切换到需要保留的屏幕画面。
5. 点击「立即锁定操作」，或按 `Ctrl+Alt+L`。
6. 解锁时可再次按 `Ctrl+Alt+L`，或点击主屏幕右下角的「解锁」按钮。
7. 输入普通密码后按 Enter 或点击「解锁」。点击「取消」只关闭密码框，不会解除锁定。
8. 普通密码连续输错 10 次后需等待 5 分钟；冷却期间仍可直接连续输入 Admin 密码解控。

## Admin 全局解锁

1. 确保已提前在设置页保存 Admin 密码。
2. 在锁屏层、普通密码框或错误冷却界面中，直接用键盘连续输入完整 Admin 密码，无需点击鼠标或按 Enter。
3. 验证成功后立即解除锁定，清除普通密码失败次数和冷却状态，并显示一秒「Admin 解锁」提示。

鼠标操作不会打断连续输入。未设置 Admin 密码时无法使用该功能，代码中没有固定或通用密码。输入序列仅用于插件自身的哈希比对，不写日志、不保存明文。

## 注销恢复与允许锁定时段

- 注销时如果插件处于锁定状态，下次 ClassIsland 启动会尝试恢复锁定；关机或重启则清除恢复状态。
- 正常退出 ClassIsland 时若仍处于锁定状态，也会记录恢复状态；强制结束进程无法保证记录。
- 设置页可启用「允许锁定时段」。时段外不允许新锁定，已有锁定会在 15 秒内自动解除。
- 支持跨午夜时段，例如 `18:00` 至次日 `07:00`；起止时间相同表示全天允许。恢复锁定同样受此时段限制。

## 安全说明

本插件是用户态操作限制工具，不是 Windows 安全边界：

- `Ctrl+Alt+Delete` 和注销始终由 Windows 管理，插件不能拦截；注销恢复依赖 ClassIsland 下次正常启动。
- 插件不会隐藏任务管理器中的 ClassIsland 进程，也不能阻止断电、强制重启或管理员结束进程。
- 停止插件或退出 ClassIsland 会解除输入隔离。学校设备应通过 Windows 组策略、AppLocker 或 kiosk 配置限制任务管理器、注销和进程结束权限。
- 不应将其用于保护高敏感数据或替代系统账户权限管理。

## 从源码构建

```powershell
dotnet build -c Release -p:CreateCipx=true
```

如果构建环境只有 Windows PowerShell，可额外指定：

```powershell
dotnet build -c Release -p:CreateCipx=true -p:PowershellBinaryName=powershell
```

插件包和 MD5 校验信息输出到 `cipx/` 目录。
