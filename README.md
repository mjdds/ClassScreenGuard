# 教室屏幕操作锁

<img src="icon.png" alt="教室屏幕操作锁图标" width="128" />

ClassScreenGuard 是一个适用于 **ClassIsland 2.x** 的 Windows 屏幕操作锁插件。锁定后保留当前画面和正在播放的内容，不显示全屏遮挡层，同时限制鼠标、触摸和普通键盘输入，适合课堂教学、展示等需要临时限制教室电脑操作的场景。

## 重要：密码设置入口

> 在 ClassIsland 的「屏幕操作锁设置」页面，**连续点击页面上的版本号 5 次**，相邻两次点击间隔不超过 **2 秒**，即可展开隐藏的密码修改区域。
>
> 密码修改区域会在本次设置页打开期间保持可见。首次使用前，请先设置普通密码和 Admin 密码，并在确认两种解锁方式均可用后再正式使用。

## 功能特性

- **保留原画面**：锁定期间不遮挡课件、视频或其他正在展示的内容。
- **多显示器输入隔离**：透明输入隔离层覆盖所有显示器，拦截其他窗口的鼠标、触摸和长按操作。
- **减少 Shell 绕过**：锁定期间关闭通知中心、开始菜单和搜索等 Shell 浮层。
- **快捷键锁定**：按 `Ctrl+Alt+L` 立即锁定，再次按下可打开密码框。
- **触摸解锁入口**：主显示器右下角常驻「解锁」按钮，支持鼠标和触摸。
- **双密码解锁**：支持普通密码和管理员 Admin 密码。
- **Admin 全局解锁**：无需先打开密码框，连续输入正确的 Admin 密码即可解控。
- **失败冷却**：普通密码连续输错 10 次后冷却 5 分钟，重启插件不会清除冷却状态。
- **允许锁定时段**：仅在指定时段内允许锁定，支持跨午夜；时段外自动解除已有锁定。
- **注销恢复**：注销后可于下次启动 ClassIsland 时恢复锁定，关机或重启则清除恢复状态。
- **密码安全存储**：普通密码与 Admin 密码均使用随机盐和 PBKDF2-SHA256 哈希保存，不保存明文。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / Windows 11 |
| 宿主程序 | ClassIsland 2.x |
| 插件 API | 2.0.0.0 或更高版本 |
| 源码构建 | .NET 8 SDK |

本插件使用 Windows 输入钩子和窗口 API，不支持 Linux 或 macOS。

## 安装

### 手动安装

1. 前往 [Releases 页面](https://github.com/mjdds/ClassScreenGuard/releases/latest)，下载最新版 `ClassScreenGuard.cipx`。
2. 打开 ClassIsland 的插件设置，安装下载的 `.cipx` 文件。
3. 按 ClassIsland 提示重启或重新加载插件。
4. 在 ClassIsland 设置中找到「屏幕操作锁设置」。

### 插件市场

插件市场上架审核通过后，也可以在 ClassIsland 插件市场中搜索「教室屏幕操作锁」并安装。

## 快速开始

1. 打开「屏幕操作锁设置」。
2. 按[密码设置入口](#重要密码设置入口)中的说明展开密码修改区域。
3. 设置并保存普通解锁密码和 Admin 密码。
   - 两种密码均至少包含 4 个字符，建议使用 8 位以上密码。
   - Admin 密码需要直接连续输入，建议使用字母、数字和可直接输入的符号，避免依赖中文输入法候选。
   - 首次设置 Admin 密码无需原密码；已经设置后，修改前必须验证原 Admin 密码。
4. 切换到需要保留的屏幕画面。
5. 点击「立即锁定操作」，或按 `Ctrl+Alt+L`。
6. 解锁时再次按 `Ctrl+Alt+L`，或点击主屏幕右下角的「解锁」按钮。
7. 输入普通密码，然后按 Enter 或点击密码框中的「解锁」。

> 点击密码框中的「取消」只会关闭密码框，不会解除锁定。

## 解锁方式

| 场景 | 操作 |
| --- | --- |
| 打开密码框 | 按 `Ctrl+Alt+L`，或点击主屏幕右下角「解锁」按钮 |
| 普通密码解锁 | 输入普通密码，按 Enter 或点击「解锁」 |
| Admin 全局解锁 | 在任意锁定界面直接连续输入完整 Admin 密码，无需点击或按 Enter |
| 暂时关闭密码框 | 点击「取消」，屏幕仍保持锁定 |

### Admin 全局解锁

Admin 解锁在锁屏层、普通密码框和错误冷却界面中均可使用：

1. 确保已提前在设置页保存 Admin 密码。
2. 直接使用键盘连续输入完整 Admin 密码。
3. 验证成功后立即解除锁定，清除普通密码失败次数和冷却状态，并显示一秒「Admin 解锁」提示。

鼠标操作不会打断 Admin 密码的连续输入。输入序列仅用于插件自身的哈希比对，不写日志、不保存明文。插件没有固定密码、通用密码或后门；未设置 Admin 密码时无法使用该功能。

### 普通密码错误冷却

- 普通密码最多连续输错 10 次。
- 达到上限后必须等待 5 分钟才能继续尝试普通密码。
- 失败次数和冷却截止时间会持久化，关闭密码框或重启插件不会绕过等待。
- 冷却期间仍可连续输入正确的 Admin 密码直接解控。

## 允许锁定时段

在设置页启用「允许锁定时段」，设置开始时间和结束时间后保存：

| 设置示例 | 含义 |
| --- | --- |
| `08:00` 至 `18:00` | 仅允许在当天 08:00–18:00 锁定 |
| `18:00` 至 `07:00` | 允许从当天 18:00 到次日 07:00 锁定 |
| 开始与结束时间相同 | 全天允许锁定 |

- 不在允许时段内时，快捷键和手动锁定均不会生效。
- 已有锁定会在进入非允许时段后最多约 15 秒内自动解除。
- 注销后的启动恢复同样受允许锁定时段限制。

## 注销与恢复行为

| 情况 | 下次启动行为 |
| --- | --- |
| 锁定时注销 Windows | 下次启动 ClassIsland 时尝试恢复锁定 |
| 锁定时正常退出 ClassIsland | 记录恢复状态，下次启动时尝试恢复锁定 |
| 关机或重启 Windows | 清除恢复状态，避免下次开机误锁 |
| 强制结束 ClassIsland 进程 | 无法保证恢复状态已保存 |

## 安全说明与限制

本插件是**用户态操作限制工具**，不是 Windows 安全边界，也不应替代系统账户权限管理：

- `Ctrl+Alt+Delete` 和注销始终由 Windows 管理，插件不能拦截。
- 插件不会隐藏任务管理器中的 ClassIsland 进程，也不能阻止断电、强制重启或管理员结束进程。
- 停止插件或退出 ClassIsland 会解除输入隔离。
- 注销恢复依赖 ClassIsland 下次正常启动，并受允许锁定时段限制。
- 学校或公共设备建议配合 Windows 组策略、AppLocker 或 kiosk 配置，限制任务管理器、注销和进程结束权限。
- 首次部署时请先测试普通密码和 Admin 密码，并妥善保管 Admin 密码。
- 不应将本插件用于保护高敏感数据。

## 从源码构建

在项目根目录执行：

```powershell
dotnet build -c Release -p:CreateCipx=true
```

如果构建环境只有 Windows PowerShell，可额外指定：

```powershell
dotnet build -c Release -p:CreateCipx=true -p:PowershellBinaryName=powershell
```

构建完成后，插件包和 MD5 校验信息位于 `cipx/` 目录。
